# Thomaz Augusto — Personal Portfolio

live at: https://essashr.github.io/Porfolio/

A static personal portfolio site built with plain HTML, CSS, and JavaScript —
no framework, no build step, no backend. It's designed to be deployed
directly to GitHub Pages.

Content is sourced entirely from Thomaz's resume. Where the resume didn't
provide a public link (the SetApp Junior Enterprise site and the UFV
Integrative Project), the site says so explicitly instead of linking
anywhere.

## Project structure

```
.
├── index.html          # all page content and structure
├── css/
│   └── styles.css      # design tokens, layout, components
├── js/
│   └── main.js         # mobile nav, theme toggle, card spotlight effect
├── assets/
│   └── favicon.svg      # monogram favicon
└── README.md
```
